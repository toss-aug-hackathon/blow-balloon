# 기록장 포디움 상단 간격 통일 설계

## 목적

홈 화면과 기록장 화면에서 공통으로 사용하는 상위 1~3위 카드의 순위 숫자 상단 간격을 동일하게 맞춘다.

## 확인된 차이

375×812 뷰포트의 실제 렌더링 기준:

- 홈 화면: 카드 상단부터 순위 숫자까지 `10px`
- 기록장 화면: 카드 상단부터 순위 숫자까지 약 `25~26px`

기록장 카드는 닉네임과 점수 잘림을 방지하기 위해 홈 카드보다 높게 설정됐지만, 공통 `justify-content: flex-end` 때문에 늘어난 여백이 카드 위쪽에 배치된다.

## 변경 방식

- 홈 화면 포디움 스타일은 변경하지 않는다.
- 기록장 포디움 카드만 `justify-content: flex-start`로 상단 정렬한다.
- 기록장 카드의 `padding-top`을 `9px`로 설정한다.
- 1px 테두리를 포함한 실제 순위 숫자 상단 간격을 홈과 같은 `10px`로 맞춘다.
- 기존 카드 높이와 닉네임·점수 공간은 유지해 이전 잘림 문제가 재발하지 않도록 한다.

## 제외 범위

- 홈 포디움의 크기·간격 변경
- 풍선 이미지 크기 변경
- 닉네임·점수 글꼴 변경
- 4~8위 목록 행 변경

## 검증 기준

- 375×812에서 홈과 기록장의 1·2·3위 순위 숫자 상단 간격이 각각 `10px`이다.
- 375×620에서도 기록장 카드의 닉네임과 점수가 카드 안에 완전히 들어온다.
- 크게 불기와 스피드런 탭 모두 동일한 정렬을 사용한다.
- 4~8위 목록의 높이와 정렬은 변경되지 않는다.
