# Apps in Toss 비게임 출시 체크리스트

[README로 돌아가기](../README.md)

코드와 저장소는 비게임 기준으로 전환됐습니다. 아래 항목은 Apps in Toss 콘솔과 Supabase Dashboard에서 직접 확인하거나 적용해야 합니다.

## Apps in Toss 콘솔

- 앱 카테고리를 **비게임**으로 등록합니다.
- 앱 이름 `후우풍선`, 앱 ID `hoo-balloon`, 아이콘과 대표 색상이 `granite.config.ts`와 일치하는지 확인합니다.
- 고객센터 또는 문의 URL, 운영자 정보, 개인정보 처리 안내 등 콘솔 필수 메타데이터를 채웁니다.
- 마이크 사용 목적을 `풍선을 불기 위한 바람 감지`로 설명하고, 소리를 저장하거나 서버로 전송하지 않는 실제 구현과 문구가 일치하는지 확인합니다.
- 의료 측정 앱으로 오해될 수 있는 리터·밀리리터·FVC·FEV1 표현을 사용하지 않습니다.

## Supabase 적용

1. `supabase/migrations/001_ranking_backend.sql`부터 `010_nickname_display_policy.sql`까지 순서대로 실행합니다.
2. `008`은 기존 사용자와 랭킹을 모두 삭제합니다. 개발 데이터 초기화가 승인된 전환 시점에 한 번만 실행합니다.
3. `supabase/functions/ranking-api/index.ts`를 `ranking-api` Edge Function으로 배포합니다.
4. JWT legacy secret 검증을 끄고, Service Role 키가 프런트엔드나 응답에 노출되지 않는지 확인합니다.
5. 필요하면 전환 후 `supabase/seeds/mock_ranking_data.sql`을 실행하고, 출시 전에 제거 스크립트를 실행합니다.

## 샌드박스·실기기 검수

- 앱 최초 진입만으로 마이크 권한 창이 뜨지 않습니다.
- 모드 선택 후 설명 화면에서 사용자가 버튼을 눌렀을 때만 권한을 요청합니다.
- 권한 허용, 거부, 재시도와 주변 소음 보정이 iOS와 Android에서 동작합니다.
- Toss 상단 뒤로가기는 플레이 중 종료 확인을 띄우고, 홈에서는 앱을 닫습니다.
- Toss 홈 버튼은 마이크와 애니메이션을 정리한 뒤 앱 홈으로 이동합니다.
- 화면 확대 제스처가 비활성화되고, safe area와 상단 내비게이션이 겹치지 않습니다.
- `getAnonymousKey()` 성공 사용자는 별명과 기록을 저장할 수 있고, 식별 실패 시에도 로컬 플레이는 가능합니다.
- 랭킹에 별명과 4자리 표시 ID만 노출되고 익명 키는 응답이나 화면에 노출되지 않습니다.
- 기존 랭킹이 초기화됐고 새 비게임 사용자 기록만 쌓이는지 확인합니다.
- 두 모드, 결과 화면, 재도전, 기록장, 백그라운드 복귀를 실제 iPhone과 Android에서 점검합니다.

코드 변경만으로 콘솔 등록이나 원격 데이터베이스 적용·배포는 완료되지 않습니다. 위 외부 작업은 대상 프로젝트를 확인한 뒤 직접 실행해야 합니다.
